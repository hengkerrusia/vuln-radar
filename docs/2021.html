Apache 2.4.49 path traversal (CVE-2021-41773)🧪 lab

2021 — Ash Daulton (HackerOne #1394916)
Path Traversal

Disclosed H1 report ($4,000 Internet Bug Bounty on the report page): 2.4.49 checked the path for ../ BEFORE decoding %2e to ., so /.%2e/ segments became live traversal after the check. With ScriptAlias /cgi-bin/ + mod_cgi, a GET reads files outside the web root (e.g. /etc/passwd). Fix is config hardening (Require all denied, per the official advisory); 2.4.50's fix was incomplete (CVE-2021-42013), so the upgrade note says >= 2.4.51.
