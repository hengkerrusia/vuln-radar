CVE-2023-22515: Confluence BFLA → rantai setup → admin takeover🧪 lab

2023 — Atlassian
BFLA

GET /server-info.action with XWork-style parameter binding bootstrapStatusProvider.applicationConfig.setupComplete=0 flips setup state on an already-configured instance — broken function-level authorization on /setup/*, CWE-285. Attacker chains setupadministrator-start → setupadministrator.action to create an administrator, then dologin → full ATO with zero authentication. Affects Confluence Data Center/Server 8.0.0–8.5.1 (fixed 8.3.3/8.4.3/8.5.2+), CVSS 10.0, CISA KEV, exploited by nation-state actors. Lab: lightweight stdlib-only mock; exploit contract STATUS/ADMIN_TOKEN, token proven via independent /me oracle (is_admin); fix = /server-info.action read-only + /setup/* → 403 after setup complete (fail-closed, mirrors Atlassian's interim mitigation).

CVE-2023-28131: Expo OAuth proxy open redirect → ATO🧪 lab

2023 — Salt Labs (Salt Security)
Open Redirect

AuthSession proxy (auth.expo.io) stored attacker-influenced returnUrl in an ru cookie, then redirected the OAuth fragment (code+token) to it — the case-sensitive scheme check was bypassed with mixed-case hTTps://. Full ATO demonstrated on Codecademy. CVSS 9.6, hotfixed within hours. Lab: mock OAuth proxy + IdP, no browser needed; fix = case-insensitive scheme + host allowlist (400).
